# 비정상 수용 광맥도

원스휴먼(Once Human) **비정상 수용(Deviation Secure)** 맵의 광물 분포를 지역보다 더 잘게 나눠 보여주는 웹페이지입니다.
"블랙펠 서부에 철이 많다" 수준이 아니라, "올드쉽 농장 근처 해안 언덕에 텅스텐·금이 몰려 있다"처럼 **구역 단위**로 정리했습니다.

## 주요 기능

- **밀집 구역 37곳 표시**: 11개 지역 안에서 광맥이 몰린 곳을 번호 핀으로 표시합니다.
- **광물별 필터**: 텅스텐, 금, 스타더스트, 은, 철, 구리, 유황 중 하나를 고르면 그 광물이 나오는 구역만 남고, 지역 목록도 매장량 순으로 정렬됩니다.
- **구역 상세 정보**: 각 구역마다 가까운 랜드마크 기준 위치, 해안가/내륙 여부, 해발 고도, 반경 약 400m 안의 광물 구성을 보여줍니다.
- **지역별 광물 비율 막대**: 지역마다 어떤 광물 비중이 높은지 한눈에 비교할 수 있습니다.
- 다크 모드, 모바일 화면을 지원합니다.

## 한눈에 보는 요약

| 찾는 광물 | 추천 구역 |
|---|---|
| 텅스텐·금 | 낙원 중심 뒤집힌 유적 동쪽, 부동항 지역 올드쉽 농장 언덕, 이글루 베이 버려진 은신처 남쪽 해안가 |
| 스타더스트·은 | 블랙펠 북부 썬샤인 농장 북동쪽 고원, 아이언리버 하류 리플비 북서쪽 강변 |
| 철·구리·유황 | 아이언리버 하류, 블랙펠 서부 |
| 한 번에 여러 종류 | 부동항 올드쉽 농장, 낙원 중심 뒤집힌 유적 동쪽 (일곱 종류 모두 나옴) |

## 데이터와 분석 방법

- **원본 데이터**: [oncehuman.th.gl](https://oncehuman.th.gl/maps/Deviation%20Secure) 인터랙티브 지도의 비정상 수용 노드 데이터 (2026-10-18 기준, 광맥 노드 8,221개)
- **지역 구분**: 같은 사이트의 지역 경계 폴리곤을 단순화해서 사용했습니다.
- **밀집 구역 계산**: 각 광맥 노드 주변 반경 약 450m 안의 노드 수를 세고, 가장 촘촘한 지점부터 서로 900m 이상 떨어지게 골라 지역마다 최대 4곳을 뽑았습니다.
- **해안 판정**: 해변에만 생기는 조개 바위(해발 약 50m) 위치를 기준으로 350m 안이면 해안가/해안 절벽, 800m 안이면 해안 인근으로 분류했습니다.
- **방향**: 지도 위쪽이 북쪽입니다.

## 주의할 점

- 표시된 곳은 **스폰 지점이 몰린 곳**입니다. 실제로 광맥이 생기는지는 서버와 채널마다 다르고, 다른 플레이어가 먼저 캤을 수도 있습니다.
- 게임 업데이트로 맵이나 스폰 위치가 바뀌면 내용이 맞지 않을 수 있습니다.
- "아게이트 툰드라"는 공식 한글 이름을 찾지 못해 음역했습니다.
- 알루미늄 광석은 이 맵에 1개, 차가운 결정 광석은 7개뿐이라 지도에는 넣지 않고 페이지 하단 메모에 적었습니다. 주석 광석은 이 맵에 없습니다.
